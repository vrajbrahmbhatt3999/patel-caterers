# Patel Caterers - Luxury Wedding & Event Catering

A premium, modern web experience for **Patel Caterers**, showcasing luxury wedding banquets, theatrical live counters, royal gastronomy, and bespoke pure vegetarian & Jain catering services.

## Features

- **Dynamic HD Video Banner**: Smooth, buffered 1080p video reel showcase with scene transitions (Wedding Banquets, Live Theatrical Counters, Grand Catering Repertoire).
- **Interactive Menu & Course Showcase**: Curated multi-course menus featuring traditional Gujarati, Marwari, Pan-Asian, and Global fusion delicacies.
- **Responsive & Modern Design**: Polished aesthetics with smooth animations, gold accents, and mobile-optimized layouts.
- **Event Planning Inquiry Form**: Direct quote requests and event consultation bookings.
- **Optimized Assets**: Fast-loading, streamlined media pipeline for seamless playback without stutter or lag.

## Tech Stack

- **HTML5 & CSS3**: Custom styles, responsive grid/flexbox layouts, CSS keyframe animations, and Tailwind utility classes.
- **JavaScript (Vanilla ES6+)**: Blob-cached video switcher, intersection observer reveal effects, interactive navigation, and form validation.

## Setup & Running Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/vrajbrahmbhatt3999/patel-caterers.git
   cd patel-caterers
   ```
2. Serve locally using any static file server, for example:
   ```bash
   npx serve .
   # or with Python
   python3 -m http.server 8000
   ```
3. Open `http://localhost:8000` in your browser.
